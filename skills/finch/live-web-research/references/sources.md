# Live Signal Sources Reference

| Source | Endpoint | Signal Type | Key Metrics Extracted |
|---|---|---|---|
| GitHub | `https://api.github.com/search/repositories` | Open-source traction | Stars, forks, language, updated_at |
| Hacker News | `https://hn.algolia.com/api/v1/search` | Developer sentiment | Points, comment count, created_at |
| arXiv | `https://export.arxiv.org/api/query` | Frontier R&D | Paper title, authors, published date |
| Wikipedia | `https://en.wikipedia.org/w/api.php` | Foundational context | Summary extract, canonical article URL |
